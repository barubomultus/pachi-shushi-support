パチ収支 - 期待値シミュレーター

予算と台を選ぶと、当たる確率・上振れ幅・期待値をシミュレーションし、実際の収支記録と比べられるアプリです。

お問い合わせ・不具合報告

GitHub Issues から送ってください（GitHubアカウントが必要です）。

機種データについて

機種スペックは P-WORLD・DMMぱちタウン等の公表値をもとにした参考値です。RUSH中の平均出玉は公表ボーダーと一致するよう補正しています。実機の結果を保証するものではありません。

注意

本アプリは収支の目安を計算するツールで、遊技を勧めるものではありません。のめり込みが心配な方は「リカバリーサポート・ネットワーク」（0120-683-705）にご相談ください。
